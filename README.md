# LocalToolbox

基于 Tauri 2、Vue 3、TypeScript 和 Rust 的 Windows 本地工具箱，当前源码已注册 81 款内置工具。工具在本机运行，不需要自建后端或线上数据库。

源码仓库：[t000j/local-toolbox](https://github.com/t000j/local-toolbox)。采用 [MIT License](LICENSE)，第三方依赖遵循各自许可证。

## 开发环境

- Node.js 24 LTS 与 npm
- Rust stable 工具链
- Windows C++ Build Tools
- Microsoft Edge WebView2 Runtime

## 启动界面

1. 在本目录运行 npm install 安装前端依赖。
2. 运行 npm run tauri dev 启动桌面开发模式。
3. 如需先在浏览器查看界面，可运行 npm run dev；系统集成功能以后续 Tauri 模式为准。

## 安装包与自动更新

- 产品名为 LocalToolbox，开发包名为 local-toolbox，主程序为 LocalToolbox.exe；工具名称与操作提示保留中文。
- 采用单实例运行；再次启动会显示、还原并唤起已有窗口。
- Windows x64 使用 NSIS，简体中文安装向导，默认安装到 `%LOCALAPPDATA%\Programs\LocalToolbox`。
- “关于与更新”显示实际应用版本；正式版本默认启动 3.5 秒后检查更新，发现新版本时显示顶部提醒及侧栏“有更新”标记；可选择稍后、手动检查或关闭自动检查。
- 更新从 GitHub Releases 下载，验证签名后由用户确认安装。正在执行本机工具任务时禁止安装。
- 发布工作流仅由版本标签或手动触发，生成 Release 草稿；推送普通源码提交不触发构建。
- 更新签名私钥及密码保存在被 Git 忽略的 `.secrets/` 中，对应的 GitHub Actions Secrets 已配置，源码仓库只包含公钥。
- [LocalToolbox 0.1.2](https://github.com/t000j/local-toolbox/releases/tag/v0.1.2) 已正式发布，安装包、更新签名及 latest.json 可公开下载；已安装的英文版 0.1.0 / 0.1.1 可在“关于与更新”检查更新。

详见 [发布与更新指南](docs/RELEASING.md)、[产品规划](本地工具箱-产品规划与技术选型.md)。直接维护项目根目录这一份规划文档，并随代码提交。

准备自己发布新版本时，按 [新版本发布教程](docs/HOW_TO_RELEASE.md) 操作；教程包含版本同步、更新说明、源码推送、Actions 构建、正式发布和旧版更新验证。

## 当前功能

- 文本文件编码转换：UTF-8、UTF-16LE/BE、ASCII 与 ISO-8859-1（Latin-1），手动选择源/目标及 BOM 策略；严格拒绝无效字节、孤立代理项和不可表示字符，精确往返验证，不修改换行/空白。4 MiB 输入、16 MiB 输出、10 秒后台超时，可取消；正文预览后通过安全句柄另存为新文件，不覆盖原件。暂不支持 GBK/GB18030 等其他编码。

- 文件校验和验证：手动选择 MD5、SHA-1、SHA-256/384/512，以纯十六进制或 GNU/BSD 单条记录检查本地文件内容；严格长度/格式/算法解析，记录文件名须与所选文件完全一致。复用 1 MiB 分块摘要、256 MiB 文件上限、30 秒 Worker 超时与取消；明确展示匹配/不匹配、预期及实际值，不上传/修改文件。

- ZIP 压缩包管理（部分实现）：选择最多 200 个/合计 16 MiB 文件创建 ZIP，浏览最多 32 MiB 包内目录，逐项解压后明确另存；支持存储与 Deflate，解压核验 CRC32。拒绝危险路径、链接、重复/冲突名称、加密/分卷/ZIP64 与超预算输入；线程可取消，另存通过安全句柄只创建新文件。尚不支持整包目录恢复与空目录导出，Windows 保存与界面未验证。

- 文件分割与合并：手动确认源/目标后以 256 KiB 缓冲处理二进制，按 1–64 MiB 分块，最多 512 MiB / 512 块。清单记录顺序、大小、每块及总 SHA-256，合并核验后回读输出；空文件可往返。输出逐级句柄验证、只新建不覆盖，异常或取消清理未提交文件；120 秒为协作时限，慢 IO 可能延迟取消，最终提交阶段不可中断，崩溃或设备故障可能残留已完成分块。仅接受本工具 v1 清单，不删除源或分块，校验和不证明来源可信。

- 文件清单导出：只读扫描明确选择的本地子目录，预览文件/目录相对路径、大小及 UTC 修改时间，手动导出 CSV 或文本。CSV 带 UTF-8 BOM、CRLF、引号转义及公式前缀防护；文本路径使用 JSON 转义。不完整清单需明确勾选并携带状态标记，最大 1 MiB；输出路径逐级句柄验证，仅新建、拒绝覆盖，失败通过句柄清理未完成输出。

- 文件夹结构比较：手动选择两个本地子文件夹，按相对路径（区分大小写）比较文件/目录类型、文件大小与修改时间；包含空目录。复用只读句柄遍历保护，各侧 30 秒/1,000 条，支持取消及分页；不完整侧缺失标为未知，元数据相同不代表内容相同。按左→右实时读取，不同步、不改文件。

- 重复文件查找：只扫描手动选择的本地子文件夹，先按大小筛选候选，再通过已核验文件句柄分块计算完整 SHA-256；仅显示大小与摘要相同的至少两个文件，不以名称或大小直接判重。每文件 64 MiB、累计读取 512 MiB；复用搜索的遍历/输出/时间上限，检查文件标识、大小及变更时间，跳过变化、占用、权限错误和硬链接别名。允许取消并展示部分候选；无清理、删除、移动或自动保存，结果为有界实时读取而非一致性快照。

- 本地文件搜索：只扫描手动选择的本地子文件夹，按字面文件名、扩展名、字节大小与修改时间组合筛选；句柄相对遍历，保留只读目录句柄并拒绝链接/重解析点、网络或设备路径。最多 10,000 项、32 层、1,000 目录、1,000 结果、64 KiB 输出、30 秒，可取消；权限/占用/上限等跳过原因可见，不自动保存、不读文件正文。

- 显示器信息查看：手动只读读取最多 32 台显示器的物理分辨率、系统缩放、主屏和桌面坐标，绘制含负坐标与镜像重叠的排列示意；不截图、不更改显示设置，无新增依赖。

- 电源操作面板：锁屏、睡眠、注销、重启及关机，逐次影响预览与明确确认；仅本页 10 秒倒计时，可取消或离页取消，之后单次提交。关机/重启使用 /t 0 而无 /f，避免延迟参数隐含强制；不提权、不调整系统保护、不全局取消他人定时任务，不自动重试；系统可能阻止操作，返回成功不等于最终状态核验。

- 防火墙规则查看：手动只读查询 ActiveStore 规则，搜索名称、端口、地址、应用及服务，按方向与启用状态筛选、25 行分页。1000 条 / 64 KiB / 20 秒总限额，取消与不完整结果显式提示；不改规则、不提权、不探测网络。规则编辑为可选扩展，不属于本次查看器完成条件。

- Hosts 文件查看与编辑：固定系统路径，严格 UTF-8 / ASCII 与可选 BOM，256 KiB 上限；预览逐行差异并明确确认，独占句柄校验原始字节冲突，原目录创建不覆盖备份并核验后原位保存，保留权限并写后核验。拒绝重解析点及硬链接，不提权、不自动刷新 DNS、不自动恢复；失败可能部分写入，保留备份并提示手动检查。

- 环境变量查看与编辑：查看用户与系统持久变量原始值，仅逐项预览确认后修改既有普通用户字符串变量；敏感名称内容不读取，PATH 等保护名称及系统变量只读，不新增或删除。保留值类型、写前比对、写后核验与只读重查；不广播更新，后续登录生效，不自动备份/回滚。系统编辑等未覆盖，部分实现。

- 开机启动项管理：仅当前用户 64 位 HKCU Run 字符串值及 LocalToolbox 专用未加密备份；逐项确认后备份、核验并禁用，恢复只写入不存在的目标且保留备份；冲突不覆盖，不执行命令。不含启动文件夹、计划任务、RunOnce、32 位/全机项或 StartupApproved 标记，因此部分实现；写前比对与写后核验、取消后只读重查，不自动重试。

- Windows 服务管理器：手动只读读取服务；逐项预览名称、范围、旧/新状态与影响，确认后允许无依赖服务启动、无被依赖服务停止；不改启动类型、不强制停止、不提权。写前核对状态、写后验证并只读重查；20 秒、500 条、64 KiB 上限，取消或超时不自动回滚或重试。依赖服务操作未覆盖，因此标为部分实现。

- 进程查看器：手动读取本机进程快照，按名称 / PID 筛选、按工作集内存或累计 CPU 秒数排序，50 行分页；CPU 为进程累计处理器时间而非瞬时百分比。只读、不结束进程、不提权、不读取命令行或环境变量、不自动刷新或保存；受总时限、行数和输出大小限制，可取消。

- HTTP 请求调试器：仅手动向用户指定 HTTP / HTTPS 地址发送请求，支持方法、请求头、UTF-8 正文和纯文本响应；禁用自动重定向、默认凭据、Cookie、代理及客户端证书，不绕过 TLS 验证。输入仅 stdin JSON，不进入进程参数、日志或磁盘；受请求大小、响应大小和总时限限制，可取消，离页清空。响应不执行 HTML。取消不能撤销服务器已处理的请求。

- 局域网设备发现：仅手动探测已连接 Ethernet / Wi-Fi 的 RFC1918 私有 IPv4 子网中的 /26–/30 范围，最多 62 个地址、并发 1、每台 1 次 ICMP / 500 毫秒，总时限 40 秒。后端再次验证范围和本机实际子网；不扫描端口、不反向解析、不自动保存。用户必须明确确认有权探测；无响应不能认定离线。输入通过 stdin JSON，固定内置脚本，取消/超时复用进程树清理。

- TCP 连接查看器：手动读取 IPv4/IPv6 TCP 连接与监听快照，显示本地/远端地址、状态、PID 与尽力匹配的进程名；本机筛选、50 行分页、最多 2000 行。netstat 与 tasklist 合计 20 秒，每份输出最多 64 KiB，不自动刷新、不解析远端域名、不结束进程

- DNS 缓存查看与刷新：手动查看 Windows DNS 缓存；清空前显示影响并二次确认，命令不自动提权，权限不足显示失败；取消不能撤销已清空的缓存。15 秒总时限、64 KiB 原始输出，缓存可能包含访问域名，仅本机显示且不保存

- DNS 查询：手动向默认 DNS 服务器查询 A / AAAA / CNAME / MX / TXT / NS / SOA / PTR；ASCII 域名或 IP，域名按完整名称查询，不添加搜索后缀；15 秒总时限、64 KiB 原始输出，不把退出码等同于解析成功

- 路由追踪：手动调用 Windows tracert，最大 1–30 跳、每次等待 250–2000 毫秒、总时限 60 秒；取消或超时保留部分结果，禁止自动反向解析中间节点，输出上限 64 KiB

- Ping 测试：仅手动向指定主机/IP 发送 1–10 次探测，每次等待 250–2000 毫秒、总时限 30 秒；可取消，保留原始响应/统计，输出上限 64 KiB。主机名使用系统 DNS，不自动运行、不保存结果

- 分类浏览和关键词搜索
- Ctrl+K 聚焦搜索框，Esc 从工具页返回
- 收藏状态保存在当前设备的浏览器存储中
- JSON 格式化与压缩
- JSONPath 查询器：支持 RFC 9535 路径、通配符、递归、切片及筛选，显示命中路径和值；后台查询、分页复制、取消与超时保护
- JSON 差异比较：忽略对象键顺序，按路径展示新增、删除、修改；数组按索引比较
- XML 格式化与结构校验：保留混合文本和 CDATA，拒绝 DTD 与实体声明
- YAML 格式化、校验与 JSON 互转：本机处理 YAML 1.2 的 JSON 兼容子集，限制别名展开并防止数值精度丢失
- CSV 表格查看器：本地 UTF-8 文件或粘贴输入，支持引号与多行字段、分页筛选及 JSON 导出，值保留为字符串
- SQL 格式化器：按方言整理缩进与关键字大小写，不执行语句
- Markdown 预览器：本机编辑并预览净化后的 HTML，不加载外部资源
- 正则表达式测试器：后台匹配，显示位置与捕获组，支持超时取消
- 文本差异比较：逐行标记新增与删除，分页筛选变化行，后台比较并支持取消
- Base64 文本与文件编解码：UTF-8 文本、任意本地文件编码、二进制解码保存；原始文件/结果最多 4 MiB
- URL 编解码：单个参数、完整 URI 与表单字段三种模式，严格校验百分号与 UTF-8，最多 100,000 字符
- HTML 实体编解码：常见命名实体、十进制/十六进制数字实体，支持非 ASCII 编码；只显示纯文本，不执行 HTML
- Unicode 查看与转义：分页查看码点、UTF-16 码元和偏移，互转字面 Unicode 转义，明确标记孤立代理项
- JWT 内容查看器：本机解码 Header/Payload 原始 JSON，不验证签名或可信性，不联网、不保存令牌
- 测试数据生成器：可选虚构姓名、example.invalid 示例邮箱、日期等字段，固定虚构标记；可复现种子、1–1000 条，支持 JSON / CSV / SQLite SQL 复制与下载，不执行 SQL
- 随机数与字符串：含上下界整数、自定义 Unicode 字符池、数量与长度设置；安全随机源与拒绝采样，允许重复
- 密码生成器：安全随机源、长度/数量/字符类型设置，可排除易混淆字符；不保存密码，复制前提示剪贴板历史风险
- UUID v4 生成器：生成 1–100 个随机标识并复制
- 哈希摘要：UTF-8 文本及本地文件分块计算 MD5、SHA-1 和 SHA-256/384/512，最多 256 MiB 文件，支持取消与超时；弱算法显示安全提示
- Unix 时间戳与本地日期时间转换
- 计算器：四则运算、括号、小数、实时结果和本次会话历史
- 日期间隔计算器：显示相差天数、含首尾的日历天数和含首尾的周一至周五工作日数
- 时区换算器：使用本机时区数据换算日期时间，识别夏令时跳时与重复时刻
- 世界时钟：同时查看本机和多个自选城市的实时日期时间，选择保存在本机
- 秒表与倒计时：秒表支持暂停、复位和计次；倒计时支持快捷时长与到时提示
- 折扣、税额与分摊：计算折后价、含税金额；按分配平多人分摊余数
- Emoji 与特殊字符：按分类或关键词搜索内置字符，点击即可复制
- 剪贴板历史：默认关闭，仅在本工具页手动开启期间读取；支持搜索、复制和清理，最多保留 20/50/100 条，单条文本上限 512 KB、图片上限 8 MB、总量上限 64 MB。历史存于本机 IndexedDB 且未加密；暂停不会删除已有记录
- 粘贴为纯文本：手动读取并预览剪贴板文字，确认后写回纯文本，移除富文本格式；不会自动读取或保存内容
- 文本片段管理器：保存、搜索、编辑、删除并一键复制常用文本，最多 100 条；名称最多 80 个字符、单条正文最多 10,000 个字符，保存在本机且不加密
- 多项粘贴队列：临时整理最多 50 条文本，调整顺序后逐项复制；用户在目标程序手动粘贴，离开页面后队列清空
- 区域截图：经 WebView2 屏幕选择器选择屏幕或窗口，工具窗口短暂隐藏后框选区域；可复制或保存 PNG，截图仅在本机处理
- 截图标注：打开本地图片或直接截取屏幕，添加箭头、画笔和文字后复制或另存 PNG；不覆盖已有文件
- 屏幕标尺：选择屏幕或窗口后拖动测量线，查看水平、垂直、直线像素距离及角度；结果按捕获画面像素计算
- 长度、质量、面积、体积、速度、温度和数据容量换算
- 本机二维码生成与 PNG / SVG 保存
- 条形码生成：CODE128、EAN-13、EAN-8、UPC-A、CODE39，支持 PNG / SVG 导出
- 文本清理器：逐行去空格、删除空行、删除重复行、排序并统一换行格式，支持即时预览与复制
- 批量重命名：前后缀添加或文件名查找替换，先预览冲突，确认后改名并支持撤销
- 图片尺寸调整：单张或最多 8 张静态 PNG/JPEG，按像素或比例缩放；EXIF 方向校正、保持比例可选，预览后逐张安全另存 PNG。输入/输出各 16 MiB/张、32 MiB/批，8192 边长/1600 万像素，30 秒线程超时；不保证色彩配置/高位深保真，不保留原元数据
- 图片格式转换：Rust `image` 本机转换 PNG、JPG、GIF、WebP、BMP、TIFF；JPEG 可调质量，WebP 无损输出，另存且不覆盖现有文件
- 图片压缩：JPEG 可调质量，PNG 使用无损高压缩；先生成预览并比较实际文件体积，再另存结果
- 本机网卡、IPv4/IPv6 地址、网关、DNS 和 MAC 信息（只读）
- TCP 端口占用查询按进程合并显示，将监听地址与活动连接分开呈现
- 结束占用端口的进程前二次确认，并重新校验端口和 PID
- 系统与设备概览：Windows 版本、CPU、内存、架构和运行时长
- 窗口置顶与快速控制：列出桌面窗口并搜索，支持置顶、取消置顶、最小化、最大化、还原和确认后请求关闭

- 磁盘空间分析器：查看磁盘容量、选定目录占用和大文件，有限扫描并标明跳过与部分结果
- 临时文件清理：预览用户 Temp 中超过 7 天的文件，手动选择并二次确认后永久删除，变化或被占用文件跳过
- 已安装应用查看器：只读查询软件登记信息与商店应用，可搜索版本、发布者、安装范围和位置
- Windows 事件日志筛选器：筛选系统/应用事件，按时间、级别和来源查询，查看并复制消息详情
- 电池与电源报告：查看电池电量、设计/满充容量和电源计划，可另存 Windows HTML 电池报告
- 系统诊断报告：汇总系统与磁盘信息，网络配置按需加入，支持预览、复制和 JSON/TXT 另存
- 文件权限查看器：只读查看文件和目录所有者、允许/拒绝条目与继承状态，支持搜索与复制
- 证书查看器：查看用户或本机个人/根/中间证书的公开信息和有效期，支持搜索与复制，不读取私钥
- 设备与驱动清单：只读查看最多 2000 条设备信息，按名称、厂商、类型、状态和驱动版本筛选，查看与复制驱动登记详情
- 设置备份与恢复：按分组导出本机偏好和收藏，可选文本片段/工作区；校验并预览后确认恢复，JSON 文件上限 4 MiB
- 工具按文本与数据、哈希与校验、系统与网络、文件与媒体、日常效率分类；Base64 属于编码，不称为加密。二维码和条形码均在本机生成

当前源码包含 71 款内置工具，线上正式版 0.1.2 包含 41 款。后续源码功能尚未打包发布；前端构建检查通过，Windows 实机、原生剪贴板和下载仍待验证。下一版说明见 docs/release-notes/0.1.3.md。没有插件市场、业务服务端或线上数据存储；Ping、路由追踪与 DNS 查询按用户指定目标联网；版本检查和安装包下载为可选联网功能。
