# 窗口移动（规划 #39）

现有窗口快捷管理补齐移动：普通可见顶级窗口显示当前位置，输入桌面物理像素 X/Y（支持负坐标），
逐次展示窗口标题、进程、PID 与旧/新坐标，勾选确认后单次提交。最大化/最小化窗口需先由用户还原。
不改变尺寸、Z 顺序、焦点或置顶状态，不自动提权，不控制本工具、桌面或 Shell 窗口。

- 前后端限制整数坐标 ±100000；后端拒绝未确认、无效句柄/进程、非正尺寸与异常参数
- PowerShell 调用线程使用 Per-Monitor-V2 DPI 感知，读取位置和移动使用同一物理坐标系
- 写前核验 HWND、PID、标题、可见/普通状态与完整矩形；紧接移动前再次核验身份与矩形
- 目标必须保留窗口顶部至少 32 像素高、64 像素宽（小窗口取实际尺寸）在当前某显示器工作区
- SetWindowPos 只移动；写后检查实际位置及尺寸，应用拒绝/自行调整时报告失败，不谎报成功
- 失败后清空过期列表并要求刷新；取消、改坐标、刷新、其他操作或离页撤销未提交确认
- 已提交的移动不能通过离页撤销；多进程竞争无法形成原子快照，操作后应用仍可能自行移动

本次补齐 #39 的移动需求；#89 原有置顶/关闭复用不变，注册工具数不变。
`node scripts/check-window-movement.cjs` 仅源码/模拟检查，不移动真实窗口。
Windows 原生编译、DPI 混合显示器、受限/管理员窗口和真实窗口交互尚待实机验证；未打包发布。
