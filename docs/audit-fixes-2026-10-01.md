## 资源受限云环境复现命令

完整前端类型检查仍使用 `./node_modules/.bin/vue-tsc --noEmit`。降低并行文件处理的生产构建不改Vite配置，可运行：

```sh
NODE_OPTIONS=--max-old-space-size=1100 node --input-type=module -e "import {build} from 'vite'; await build({build:{rollupOptions:{maxParallelFileOps:8}},worker:{rollupOptions:{maxParallelFileOps:4}}})"
```

Rust精简检查使用 `scripts/prepare-audit-native-check.py` 从当前生产源码准备忽略目录中的crate，依赖版本严格跟随项目Cargo.lock：

```sh
python3 scripts/prepare-audit-native-check.py
cargo check --manifest-path .local-tools/audit-native-check/Cargo.toml --target x86_64-pc-windows-gnu --tests --jobs 1
cargo test --manifest-path .local-tools/audit-native-check/Cargo.toml --jobs 1
```

上述命令需要已安装官方Rust stable和对应Windows标准库目标。Windows目标命令仅检查编译，不链接/执行系统调用；Linux测试仅执行生产预览比较/序列化逻辑。源代码中的截图新建/冲突临时夹具已通过目标编译但未在Windows执行。该路径不覆盖Tauri命令宏生成、整个应用链接或打包，不替代目标平台安装版验收。
