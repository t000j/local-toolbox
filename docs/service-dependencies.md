# Windows 服务依赖操作（第 33 项，受支持范围内已实现）

## 本次范围

- 服务页改为专用依赖预览流程，不再通过通用管理器直接发送单服务变更
- 手动只读读取本机普通 Windows 服务，最多 500 条；没有后台刷新、提权或远程机器参数
- 对停止的目标预览启动计划：递归读取前置服务，按依赖优先顺序启动；已运行的依赖只核验
- 对运行的目标预览停止计划：递归读取被依赖服务，按被依赖服务优先顺序停止；已停止的节点只核验
- 完整图最多 32 项；共同依赖去重，服务名使用本机规范名称，按固定序生成计划
- 界面逐项显示服务内部名、显示名、关联节点、顺序及旧/新状态，明确列出变更数量；用户勾选确认整份计划后仅提交一次
- 停止调用单目标 `ControlService(SERVICE_CONTROL_STOP)`，不使用会递归停止被依赖服务的 `ServiceController.Stop()`。有新的运行中被依赖服务时，由 SCM 拒绝，不能自动扩大停止范围

## 预览和执行保护

1. 列表完整且本页允许预览时，才可发起原生只读依赖预览；列表本身不是写入授权
2. 预览包含完整依赖闭包、当前状态和 SHA-256 指纹。指纹覆盖节点顺序、状态、显示名、关联列表及 `QueryServiceConfigW` 配置摘要；配置摘要包括启动类型、服务类型、二进制路径、账户、加载组和原始依赖列表，不把这些额外配置明文回传前端
3. 执行请求必须包含明确确认、目标状态、指纹，以及和预览相同顺序的全部服务名；Rust 拒绝缺失/超限/重复/非法服务名、旧版无计划请求及未知字段
4. 开始执行前重新生成完整计划，核对指纹和全部名称；任一状态、依赖或配置改变即拒绝，不重新计算并静默授权更大的操作范围
5. 每一步之前和之后都重新生成图并比对。每个已成功改变的节点更新期望状态，仅允许该已确认步骤的状态变化；配置或额外状态变化仍失败
6. 每次启动前还检查直接前置依赖处于运行状态；每次状态等待最多 3 秒，脚本内部预算 15 秒，外层进程总限时 20 秒，输出上限 64 KiB
7. 逐项核验后输出进度，整份计划末尾再次核验后才返回目标/动作/原指纹一致的完成回执。前端不会仅因任意一行 `verified:true` 而显示成功
8. 成功、失败、取消或超时后只读重查；不自动重试、不反向回滚。部分成功会列出已收到核验回执的服务，其他结果明确不确定

刷新、筛选、分页、关闭预览、取消等待和离页会清除待确认计划；迟到预览无法重新打开确认。重复点击不产生第二次请求；离页清空内存并通过已有诊断生命周期取消等待，不在离页后自动刷新。

## 仍有的限制

- 拒绝驱动、特殊/每用户服务类型、`+加载组` 依赖、依赖循环、缺失/不可读取节点、暂停或过渡状态、被禁用的待启动服务、不能停止的运行服务，以及超限图
- 不修改启动类型、服务配置、恢复规则或权限；不创建、删除、暂停、继续、重启服务，不强制终止进程
- 依赖图及配置/状态检查与 SCM 调用之间无法原子锁定其他程序。尤其 Windows 启动服务仍可能在极小竞态窗口中隐式启动依赖；服务程序、触发器或恢复规则本身也可能导致其他动作。因此不能承诺“系统实际影响严格只有表中服务”，界面在确认之前明确披露
- 指纹不是持久授权或防恶意客户端令牌；它是本次预览和原生重新计算结果之间的冲突检测。应用内互斥锁不锁定外部服务管理工具
- 取消/进程超时不保证撤销 SCM 已接收的启动/停止请求。部分服务可能已经改变，尚在过渡或稍后再次改变；必须重读核查
- 配置摘要不包括 `QueryServiceConfig2` 扩展字段，例如故障恢复和触发器配置；不保证对所有外部配置更改进行检测
- 第33项原始查看/确认启停工作流已实现，排除项明确保留；不把源码和模拟检查称作Windows实机验收，见[范围矩阵](scope-and-verification.md)

## Windows 后续验收（须另行授权的隔离测试服务）

- 无依赖、链式、菱形共同依赖；启动已运行依赖、停止已停止被依赖节点；核对顺序和完整范围
- 在预览与提交之间改变状态、依赖配置、服务名或程序路径，确认第一步之前拒绝
- 在多步骤执行之间改变未执行节点或重新启动已停止节点，确认停止后续步骤且保留已完成回执
- 新增运行中被依赖服务，确认停止 API 返回失败而不递归停止新服务
- 权限不足、禁用服务、驱动/组依赖、暂停/过渡状态、超过 32 节点；预览全部失败关闭，不静默缩小图
- 3 秒等待超时、外层取消/20 秒终止、部分执行、离页；检查实际状态与前端“不确定”提示，不自动重试
- Windows PowerShell 5.1 C# 编译、x86/x64 `QUERY_SERVICE_CONFIGW` 布局、资源释放、真实 WebView 确认交互
