# LocalToolbox：产品规划与技术选型

- 文档状态：原型开发中
- 更新日期：2026-09-30
- 产品名称：LocalToolbox；工具名称与操作提示保留中文
- 项目代码目录：当前工作目录下的 toolbox-app/；已创建首版 Tauri + Vue 原型
- 目标平台假设：首版面向 Windows 桌面，后续是否支持 macOS/Linux 再评估

## 1. 产品定位

打造一款轻便、简洁的桌面工具箱，把开发者工具、系统操作和日常小工具集中到一个应用中。用户安装后直接使用，工具随应用内置，不需要配置服务器或安装插件。

### 产品原则

1. **本机运行**：不建设自有后端服务，不依赖云端数据库；工具在用户电脑上完成计算或调用本机系统能力。
2. **预装工具**：工具随应用版本一起发布，用户不需要发现、安装或维护插件。
3. **快捷易找**：支持分类浏览、关键词搜索、收藏和最近使用；常用工具可通过快捷键快速打开。
4. **简单可信**：每个工具说明用途、输入和结果；会修改系统状态的操作先展示影响并要求确认。
5. **联网边界清楚**：核心能力不依赖联网。确实需要访问目标网络的工具会明确标记；应用更新也可以是可选联网功能。
6. **渐进扩充**：100 项是产品候选清单，不代表首版全部实现。首版先做好一组高频工具，再按实际使用反馈增加。

### 首版非目标

- 不提供插件系统或插件市场。
- 不提供云同步、线上数据库或服务端业务接口。
- 不把任意 Shell 命令作为默认执行入口。
- 不默认静默修改系统配置、结束进程、删除文件或关闭服务。
- 不把需要第三方在线 API 的功能伪装成本地离线能力。

## 2. 技术选型

### 推荐组合

| 层次 | 选择 | 用途与原因 |
| --- | --- | --- |
| 桌面框架 | Tauri 2 | 提供桌面窗口、系统托盘、全局快捷键、安装包和本机能力调用入口；使用系统 WebView，适合轻量桌面应用 |
| 界面 | Vue 3 + Composition API | 延续熟悉的 Vue 开发方式，快速实现分类、搜索、表单和结果面板 |
| 语言 | TypeScript | 让工具输入、结果和应用状态有明确类型，减少工具数量增加后的维护成本 |
| 前端构建 | Vite | 开发和打包 Vue 前端资源 |
| 安装与更新 | NSIS + Tauri 官方 Updater + GitHub Releases | Windows x64 中文安装包，静态版本文件与签名包托管在公开仓库，无业务后端 |
| 发布流水线 | GitHub Actions + tauri-action | 版本标签或手动触发生成签名包与 Release 草稿，普通源码推送不构建 |
| 本机能力层 | Rust | 由 Tauri 主进程处理进程、端口、系统信息、文件操作等本机功能；不属于远程服务器 |
| 图像处理 | Rust `image` crate（按需启用 PNG/JPEG/GIF/WebP/BMP/TIFF 编解码器） | 本机读取和转换图片，避免转换结果依赖 WebView 的 Canvas 编码能力；不启用 AVIF 等非首版格式 |
| 本地设置 | localStorage | 当前保存收藏、工作区、世界时钟时区、文本片段及更新检查偏好；未来需要文件配置时再评估 |
| 本地结构化数据 | IndexedDB（剪贴板限量历史）；SQLite（按需） | 当前剪贴板记录有数量和容量上限，直接保存在本机浏览器数据库；将来需要大规模搜索再评估 SQLite |
| 图标与视觉 | Lucide 图标 + 自定义 CSS 设计变量 | 保持简洁一致，避免因引入重型组件体系而增加维护负担 |
| 多语言 | 本地语言资源，首版简体中文 | 文案随安装包提供；以后可补充英文，不调用在线翻译服务 |

### 架构约束

- 前端工具按内置页面和模块组织；编译时固定注册，不设计运行时插件发现、安装或升级机制。
- 纯文本转换、格式化、计算等优先在前端本地完成。
- 需要操作 Windows 的功能通过 Tauri 命令调用 Rust 本机能力；前端只传递受校验的参数。
- 调用系统命令时采用固定命令和参数白名单，不把用户输入直接拼接成 Shell 命令。
- 配置、收藏和历史保存在当前 Windows 用户的数据目录；提供清理或重置入口。
- 自动更新从 GitHub Releases 读取静态版本文件和签名安装包，只负责分发新版本，不承载工具业务数据或接口。

### 系统操作安全约束

- 结束占用端口的进程前，展示端口、进程名称、PID 和可获取到的文件路径，用户确认后再执行。
- 涉及管理员权限的操作由 Windows 正常授权流程处理，不长期以管理员身份运行整个工具箱。
- 修改 Hosts、服务、启动项、防火墙等内容时，先显示变更前后差异，再确认执行。
- 文件批量重命名、清理和转换必须先提供预览；支持取消，避免误操作。
- 只有明确需要联网的功能才发起网络请求，并在界面上标明目标和用途。

## 3. 应用主要功能

1. **首页与分类**：按工具要解决的问题浏览，当前分类为文本与数据、哈希与校验、系统与网络、日常效率；加入文件、媒体或加密工具后再显示对应分类。
2. **全局搜索**：按工具名称、别名或用途检索；对常用动作提供快捷键。
3. **统一工具页面**：提供清晰的输入区、执行按钮、结果区、复制/保存和错误提示。
4. **收藏与最近使用**：数据仅保存在本机；用户可以关闭或清除记录。
5. **系统托盘与快捷键**：允许快速呼出主窗口或搜索面板；设置中可修改和关闭快捷键。
6. **偏好设置**：主题、开机启动、快捷键、默认分类和本地数据清理。
7. **权限提示**：在首次或执行敏感系统操作前说明需要的权限及其影响。
8. **更新提示**：正式版本启动 3.5 秒后可自动检查新版本，顶部提示条与侧栏标记显示可用更新；可选择稍后或关闭自动检查，下载和安装由用户确认，断网时不影响工具使用。
9. **[已实现] 单实例启动**：再次打开应用会还原并唤起已有窗口，避免同时运行多个工具箱实例。

### 工具分类与术语

- **文本与数据**：格式化和编码等数据处理工具，例如 JSON、Base64。Base64 是编码，不是加密，任何人都可解码。
- **哈希与校验**：MD5、SHA-1、SHA-2 等单向摘要算法，用于数据比对或完整性校验；哈希结果不能解密还原。
- **加密与安全**：未来如加入加密、解密或数字签名，单独归类；加密可通过密钥还原，和哈希用途不同。
- **系统与网络**：本机网络、端口和设备信息等系统诊断工具。
- **文件与媒体、日常效率**：在有相应内置工具时显示分类，不在侧栏展示空分类；当前“文件与媒体”分类包含批量重命名。

哈希工具直接列出算法，不用“兼容旧数据”作为算法分组。选择 MD5 或 SHA-1 时再提示其不适合密码存储与防篡改等安全用途；默认使用 SHA-256。

## 4. 100 款内置工具候选清单

说明：

- **[首版候选]** 表示建议优先评估，不表示已经承诺在首版全部完成。
- **[已实现]** 表示该工具已进入当前应用原型。

## 7. 后续代码目录建议

产品方案文档放在当前工作目录根部。应用源码、依赖和构建产物放在 toolbox-app/，不与根目录中的其他项目混放。

建议代码目录初期结构：

- src/：Vue 页面、工具模块和本地化资源
- src-tauri/：Tauri 配置、Rust 命令和系统集成
- docs/：后续开发说明、工具行为规范和发布记录
- tests/：进入开发阶段后按需建立工具函数和系统操作边界检查
