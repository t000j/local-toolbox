# LocalToolbox 0.1.3

- 新增“设置备份与恢复”和“JSONPath 查询器”，当前源码内置工具增加到 54 款（尚未打包发布）。
- 按分组导出收藏、更新偏好、世界时钟等设置，可选包含文本片段与工作区路径。
- 恢复前校验并预览备份，确认后替换所选分组；收藏和更新偏好同步到当前界面。
- 备份为本机 JSON 文件，上限 4 MiB；不包含剪贴板历史、缓存、安装目录或签名密钥。
- JSONPath 支持字段、数组、递归、切片及条件筛选，显示每项命中路径和值，可复制单项或结果数组。
- 查询在本机后台线程完成，支持取消和超时保护；JSON 输入上限 1 MiB，最多保留 500 个命中，每页 25 项。

备份文件未加密，包含文本片段和工作区路径时请妥善保存。工作区恢复只保存配置，不自动启动其中的应用。

- 后续源码新增 XML / YAML / CSV / SQL / Markdown / 正则工具与文本差异比较。文本差异每段最多 100,000 字符、2000 行，统一换行符；支持分页、只看变化、复制全部和后台取消。
- 前端构建与类型检查通过；Windows 实机、浏览器视觉、原生剪贴板与下载尚未验证。正式版仍为 0.1.2（41 款）。

- 补齐 Base64 本地文件编码与二进制解码保存，复用原工具。原始内容/解码结果最多 4 MiB，标准 Base64 输入最多 6 MiB 字符；后台可取消，预览截断不影响完整复制/保存。

- 新增 URL 编解码：单个参数、完整 URI 与单个表单字段模式；空格/加号规则清晰，输入最多 100,000 字符，错误转义与无效 UTF-8 会提示。

- 新增 HTML 实体编解码：支持常见命名实体和 Unicode 数字实体，未知/缺分号实体保持原样；严格校验 Unicode，结果只作为纯文本显示。

- 新增 Unicode 查看与转义：查看码点/UTF-16 码元与偏移，每页 50 项；支持固定宽度和花括号码点转义，只解码字面文本，保留并标记孤立代理项。

- 新增 JWT 内容查看器：严格解析三段式 Base64URL/UTF-8/JSON 对象，保留原始 JSON；最多 100,000 字符，不支持 JWE。解码不等于签名验证，不应用于认证判断，不联网、不保存令牌。

- Windows 服务管理器（部分实现）：手动只读读取服务；逐项预览名称、范围、旧/新状态与影响，确认后允许无依赖服务启动、无被依赖服务停止；不改启动类型、不强制停止、不提权。写前核对状态、写后验证并只读重查；20 秒、500 条、64 KiB 上限，取消或超时不自动回滚或重试。依赖服务操作未覆盖，因此标为部分实现。 Windows 原生编译与实机尚未验证；尚未打包发布。

- 开机启动项管理（部分实现）：仅当前用户 64 位 HKCU Run 字符串值及 LocalToolbox 专用未加密备份；逐项确认后备份、核验并禁用，恢复只写入不存在的目标且保留备份；冲突不覆盖，不执行命令。不含启动文件夹、计划任务、RunOnce、32 位/全机项或 StartupApproved 标记，因此部分实现；写前比对与写后核验、取消后只读重查，不自动重试。 Windows 原生编译与实机尚未验证；尚未打包发布。

- 环境变量查看与编辑（部分实现）：查看用户与系统持久变量原始值，仅逐项预览确认后修改既有普通用户字符串变量；敏感名称内容不读取，PATH 等保护名称及系统变量只读，不新增或删除。保留值类型、写前比对、写后核验与只读重查；不广播更新，后续登录生效，不自动备份/回滚。系统编辑等未覆盖，部分实现。 Windows 原生编译与实机尚未验证；尚未打包发布。

- Hosts 文件查看与编辑：固定系统路径，严格 UTF-8 / ASCII 与可选 BOM，256 KiB 上限；预览逐行差异并明确确认，独占句柄校验原始字节冲突，原目录创建不覆盖备份并核验后原位保存，保留权限并写后核验。拒绝重解析点及硬链接，不提权、不自动刷新 DNS、不自动恢复；失败可能部分写入，保留备份并提示手动检查。 Windows 原生及实机待验证，未打包发布。
