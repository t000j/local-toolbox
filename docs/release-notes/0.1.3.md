# LocalToolbox 0.1.3

## 新增工具

- 内置工具由 41 款增加到 97 款，继续使用分类、搜索和收藏快速打开。
- 文本与数据：新增 JSONPath、XML / YAML / CSV / SQL 格式化与转换、Markdown 预览、正则测试、文本差异、URL / HTML / Unicode 编解码、JWT 内容查看及测试数据生成等工具；Base64 补齐文件编码和二进制解码保存。
- 文件：新增文件校验和、文件搜索、重复文件查找、文件夹比较、清单导出、分割与合并，以及 ZIP 文件和目录打包、浏览与恢复。
- 图片与颜色：新增尺寸调整、裁切、旋转与翻转、元数据查看和清除、屏幕取色、颜色转换、调色板及 Favicon 生成；加固原有图片转换与压缩的输入、预览和保存流程。
- PDF：新增合并、拆分、排序、旋转、图片压缩、转图片、图片转 PDF、文字提取及元数据查看。
- 系统与网络：新增进程、TCP 连接、DNS、Ping、路由追踪、HTTP 请求、局域网发现、显示器信息，以及服务、启动项、环境变量、Hosts、防火墙查看和电源操作；窗口管理补齐移动功能。
- 设置备份与恢复：按分组导出收藏、更新偏好、世界时钟等配置，可选文本片段与工作区路径；恢复前校验并预览，确认后应用所选分组。

## 使用范围

- 文件保存采用新建输出；系统修改先预览影响并明确确认，权限不足时显示结果，不自动提权。
- PDF 支持有界静态文档及常见扫描图片；加密、复杂交互结构和部分图像编码不支持，具体范围见各工具提示。本版本不包含 OCR。
- JWT 查看仅解码内容，不验证签名；图片元数据清除不保证匿名。设置备份是未加密的本机 JSON 文件，不包含剪贴板历史、安装目录或签名密钥。

## 安装与更新

- Windows x64 使用中文安装向导；已有 LocalToolbox 可在“关于与更新”下载并确认安装新版。
- 保持产品名称、应用标识和更新公钥，延续原安装位置与本机配置。
- Windows 界面、原生工具及旧版应用内升级的完整实机验收仍待完成；构建成功不代表所有工具已完成实机验证。
