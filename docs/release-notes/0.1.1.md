# LocalToolbox 0.1.1

- 新增“设备与驱动清单”，内置工具增加到 41 款。
- 支持按设备名称、厂商、驱动版本和设备实例 ID 搜索，按类型与状态筛选。
- 查看设备状态、驱动提供商、版本、日期和 Windows 签名登记，支持复制列表及单项详情。
- 软件名称、主程序和安装包统一采用 LocalToolbox，默认安装到当前用户的 Programs 目录。
- 修复首次打包中的 PowerShell 中文编码和 TypeScript 类型问题。

设备与驱动清单只读查看，不安装、卸载或修改驱动。已有 LocalToolbox 0.1.0 可通过“关于与更新”检查并下载本版本，确认后安装。
